## 🎨 Color Scheme

### Primary Colors
```
Primary Gradient: #667eea → #764ba2 (Purple/Blue)
Used for: Buttons, active states, primary elements

Secondary: #f5f7fa (Light gray)
Used for: Backgrounds, cards

Accent Dark: #333 (Dark text)
Used for: Headings, primary text

Accent Light: #666 (Medium gray)
Used for: Body text, descriptions
```

### Status Colors
```
✓ Completed:  #4CAF50 (Green)
⏳ In Progress: #FF9800 (Orange)
- Pending:    #9E9E9E (Gray)
✗ Failed:     #F44336 (Red)
```

### Tier Colors
```
Basic:    #1976d2 (Blue background)
Premium:  #c2185b (Pink background)
Corporate: #6a1b9a (Purple background)
```

## 🔄 Animations

### Tab Switch
```
Old Content: opacity 0 → 1
New Content: opacity 0 → 1
Duration: 0.3s
Effect: Smooth fade-in
```

### Level Expansion
```
Card expands downward
Tasks slide in
Duration: 0.3s smooth
```

### Progress Bar Fill
```
Width animates: 0% → target%
Duration: 0.5s
Easing: smooth
```

### Hover Effects
```
Card: slight lift (translateY -2px)
Link: underline appears
Button: background brightens
```

```

### Border Radius
```
Large elements: 12px

## 🎯 Visual Hierarchy

### Heading Sizes
```
H1 (Page Title):     36px | Font-weight: 600
H2 (Section Title):  28px | Font-weight: 600
H3 (Card Title):     18px | Font-weight: 600
H4 (Item Title):     16px | Font-weight: 600
P (Body Text):       14px | Font-weight: 400
```

### Visual Weight
```
Very Important:  Large + Dark + Bold
Important:       Medium + Dark + Semi-bold
Secondary:       Medium + Gray + Regular
Tertiary:        Small + Light + Regular
```

## 🔍 Visual Details

### Progress Bars
```
Background: Light gray (#e0e0e0)
Fill: Gradient (purple to pink)
Height: 6px (thin)
Rounded: 3px
```

### Badges
```
Shape: Rounded rectangle (border-radius: 20px)
Size: Compact (4px padding vertical, 10px horizontal)
Style: Solid background with contrast text
```

### Cards
```
Background: White or light gray
Border: 1px solid light gray
Shadow: Subtle (0 2px 8px rgba(0,0,0,0.08))
Hover: Border darkens, shadow increases
```
